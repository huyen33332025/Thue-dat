[BƯỚC 1: NẠP DATA ĐẤT TỪ n = 0 VÀO HỆ THỐNG QUY HOẠCH (Menu 3)]
3           -> Chọn Menu 3: Nhập dữ liệu các ô đất
8           -> Số lượng ô đất nạp vào thử nghiệm = 8 ô đất

* Ô ĐẤT 1 (TC_01 - HCN chuẩn tỷ lệ >= 40% dài -> Tăng 10% giá):
  1         -> Loại hình: Hình chữ nhật
  T12-Thua45-> Số tờ số thửa
  1         -> Khu vực: 1 (Trung tâm -> Hệ số KV = 2.0)
  1         -> Loại đất: 1 (Đất ở)
  1         -> Vị trí: 1 (Mặt tiền lớn -> Hệ số MT = 1.2)
  20.0      -> Chiều dài: 20m
  10.0      -> Chiều rộng: 10m (10 / 20 = 50% >= 40% -> Hệ số khuôn = 1.10)

* Ô ĐẤT 2 (TC_02 - HCN hẹp bề ngang < 3m -> Giảm 10% giá):
  1         -> Loại hình: Hình chữ nhật
  T15-Thua08-> Số tờ số thửa
  2         -> Khu vực: 2 (Ngoại ô -> Hệ số KV = 1.5)
  1         -> Loại đất: 1 (Đất ở)
  3         -> Vị trí: 3 (Hẻm nhỏ -> Hệ số MT = 0.8)
  20.0      -> Chiều dài: 20m
  2.5       -> Chiều rộng: 2.5m (< 3.0m -> Hệ số khuôn = 0.90)

* Ô ĐẤT 3 (TC_03 - Đất hình vuông khuôn đẹp -> Tăng 15% giá):
  2         -> Loại hình: Hình vuông
  T03-Thua19-> Số tờ số thửa
  1         -> Khu vực: 1 (Trung tâm -> Hệ số KV = 2.0)
  1         -> Loại đất: 1 (Đất ở)
  2         -> Vị trí: 2 (Hẻm ô tô -> Hệ số MT = 1.0)
  10.0      -> Cạnh hình vuông: 10m (Hệ số khuôn = 1.15)

* Ô ĐẤT 4 (TC_04 - HCN diện tích lớn 1000m2 -> Đánh đủ 3 bậc thuế lũy tiến):
  1         -> Loại hình: Hình chữ nhật
  T08-Thua32-> Số tờ số thửa
  3         -> Khu vực: 3 (Nông thôn -> Hệ số KV = 1.0)
  1         -> Loại đất: 1 (Đất ở)
  1         -> Vị trí: 1 (Mặt tiền lớn -> Hệ số MT = 1.2)
  50.0      -> Chiều dài: 50m
  20.0      -> Chiều rộng: 20m (Diện tích 1000m2 > 3 lần hạn mức 480m2)

* Ô ĐẤT 5 (TC_05 - Tam giác chuẩn hợp lệ):
  3         -> Loại hình: Hình tam giác
  T21-Thua99-> Số tờ số thửa

  1         -> Loại đất: 1 (Đất ở)
  2         -> Vị trí: 2 (Hẻm ô tô -> Hệ số MT = 1.0)
  15.0      -> Cạnh a: 15m
  20.0      -> Cạnh b: 20m
  25.0      -> Cạnh c: 25m (Thỏa mãn tam giác, Diện tích S = 150m2)

* Ô ĐẤT 6 (TC_06 - TESTCASE LỖI BIÊN: Kích thước chiều dài âm):

[BƯỚC 3: THỰC THI KIỂM THỬ TÍNH THUẾ & CHÍNH SÁCH MIỄN GIẢM]

2 \ 5 \ 0   -> Chọn ô 5, Đối tượng 0. Kỳ vọng: Tính diện tích tam giác Heron = 150m2, nộp 67.500 VNĐ.

[BƯỚC 4: THỰC THI KIỂM THỬ BẪY LỖI BẢO MẬT VÀ NGOẠI LỆ]
2 \ 6       -> Chọn ô đất 6 (Dài âm): Hệ thống chặn ngay lập tức, báo lỗi đỏ và từ chối tính thuế.
2 \ 7       -> Chọn ô đất 7 (Cạnh = 0): Hệ thống chặn và từ chối tính thuế.
2 \ 8       -> Chọn ô đất 8 (Tam giác sai): Hệ thống chặn, không để hàm Heron bị lỗi NaN căn số âm.
2 \ 1 \ 99  -> Chọn ô 1 nhưng nhập sai mã đối tượng = 99: Cảnh báo vàng, tự động tính theo đối tượng thường.
2 \ 999     -> Chọn STT ô đất 999 ngoài danh mục: Báo lỗi STT không tồn tại.
